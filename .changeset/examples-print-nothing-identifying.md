The examples in the README and the guides no longer print a message, a parsed model or an input excerpt to the terminal: they write it to a file, or read a field into a variable and print its length. The concepts page gains a "What is safe to log" section, and the README and the installation page say that below 1.0 a break can ship in a patch, so a caret range does not protect a consumer, and show the exact-version install. No command, option or exit code changes.
