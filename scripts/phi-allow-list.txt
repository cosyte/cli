# scripts/phi-allow-list.txt
#
# PHI-scan allow-list: the positive declaration that a fixture's identifiers
# are synthetic. `pnpm phi-scan` (`cosyte-phi-scan`) reads this file; any PHI-shaped
# token NOT covered here is a hit. Byte-strict wire formats cannot carry an
# inline `# synthetic: true` header (the header segment must be the first bytes),
# so this allow-list is the synthetic-fixture declaration mechanism: the same
# approach every sibling `@cosyte/*` parser uses.
#
# Format: `<TAG> <value>` per line. `#` comments and blank lines are ignored.
#   NAME <token>          synthetic person-name word, matched case-insensitively
#   DOB <value>           synthetic date of birth (normalize as your detector does)
#   ID <value>            synthetic id matching an SSN / MRN / member-id shape
#   EMAILDOMAIN <domain>  reserved / test email domain that is allowed to appear
#
# NOTE: the shared floor consumes EMAILDOMAIN and ID (its two shapes are SSN
# and email). NAME and DOB entries are loaded and wait for field-level
# detectors; this package parses no wire format and has none.
#
# To add a new synthetic fixture: reuse the tokens below, or append new ones here
# and commit. Adding a token is a reviewed, intentional act, never silent.

# --- Reserved / test email domains (RFC 2606 / 6761) ---
EMAILDOMAIN example.com
EMAILDOMAIN example.org
EMAILDOMAIN example.net
EMAILDOMAIN example.test

# Our own published contact domain, in `package.json`'s `author` field (hello@cosyte.com).
# The shared scan (`cosyte-phi-scan`) reads the whole repository, so it opens package.json,
# and its floor allows email domains only, not single addresses. Declared as hl7, fhir,
# mllp and astm declare it. KNOW WHAT THIS COSTS: an address at this domain anywhere in the
# tree, a fixture included, now passes the email floor; no patient data belongs at ours.
EMAILDOMAIN cosyte.com

# --- Synthetic person-name tokens (used by the CLI's parse fixtures) ---
# These are deliberately non-real sentinel tokens (prefix ZZSENTINEL) so a PHI-leak test can assert
# they never reach stderr; they positively declare the fixtures' names as synthetic.
# test/__fixtures__/adt-a01-no-visit.hl7 is adt-a01.hl7 with its visit number left out: it carries
# the same synthetic name, date of birth and id tokens as below, and no new one.
NAME ZZSENTINELLAST
NAME ZZSENTINELFIRST

# --- Synthetic dates of birth (test/__fixtures__/adt-a01.hl7, adt-a01-no-visit.hl7, patient.fhir.json) ---
DOB 19800101

# --- Synthetic ids: MRN / member-id shapes (test/__fixtures__/*) ---
ID MRN-000123
